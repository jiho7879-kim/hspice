## 1. 왜 필요한가 (1분 요약)

현재 Vmin 흐름은 SNMR의 **평균·표준편차만** 받아서 가우시안으로 Z_t=6.50까지
외삽한다. 그런데 SNMR은 버터플라이 **두 lobe의 최솟값**이고, 두 정규분포의
최솟값은 정규분포가 아니다 — **왼쪽 꼬리가 더 두껍다**. 여기에 가우시안을
맞춰 6.5σ까지 외삽하면 결과가 **낙관적**으로 나온다.

얼마나 낙관적인가:

- 본 데이터의 spec 밴드 기울기 dz/dVop ≈ 13.2 /V
- 편향 +0.7σ (두 lobe 독립 가정) → **Vmin 약 53 mV 낙관**
- T0(0.625V) → EOL(0.675V) **마진 예산 전체가 50 mV**

즉 편향이 사실이라면 **마진 예산 전체보다 큰 오차**가 sign-off 숫자에 들어가
있다. EOL 통과율로 환산하면 88.5% → 80.5% (조건의 8%가 통과→탈락).

**이 요청의 목적은 그 편향이 실제로 있는지, 있다면 크기가 얼마인지를
측정하는 것이다.** 결과가 어느 쪽으로 나오든 가치가 있다:

- 꼬리가 가우시안에 가깝다 → 현재 방법론 정당성 확보, 논란 종결
- 꼬리가 두껍다 → 보정 계수를 구해 전체 배치에 적용

## 2. 무엇을 시뮬레이션하는가

**기존 배치와 완전히 동일한 셀·덱·조건**이다. 딱 두 가지만 다르다:

| 항목 | 기존 배치 | 이번 요청 |
|---|---|---|
| 조건 수 | 2,000 | **9** |
| Vop 레벨 | 5 (0.4~0.8V) | **조건당 1개** (아래 표의 `Vop`) |
| MC 횟수 | 5,000 | **100,000** (최소 50,000) |
| 출력 | 평균·표준편차 | **샘플별 raw SNMR 전체** |

총 9 × 100,000 = **90만 회**. 기존 배치(2,000×5×5,000 = 5,000만 회) 대비
**약 1.8%** 수준이다.

> **MC 횟수를 크게 잡는 이유**: 5,000회로는 −3.5σ 부근까지밖에 관측되지
> 않아 꼬리 형상 판정이 불가능하다. 100,000회면 −4σ 부근까지 안정적으로
> 보이고, 그 범위에서 이미 두 모델이 확실히 구분된다.

## 3. 무엇을 출력해야 하는가

**샘플별 raw SNMR 값 전체** (조건당 100,000줄).

HSPICE/PrimeSim의 `.mc` + `.measure` 조합이면 **`.mt0`(또는 `.mt#`) 파일에
이미 MC 샘플당 한 줄씩** 들어있다. 그 파일이 그대로 입력으로 쓰인다 —
별도 후처리가 필요 없다.

필요한 것은 SNMR 측정값 컬럼 하나뿐이다. 평균이나 표준편차로 요약하지 말
것 — 요약해버리면 이 진단의 목적 자체가 사라진다.

## 4. 어떻게 돌리는가

`infab_snmr_tail_diag.py`를 raw 파일이 있는 곳에 두고:

```bash
# 값이 한 줄에 하나씩 있는 파일인 경우
python infab_snmr_tail_diag.py <raw파일> <deck_no> <Vop>

# 예
python infab_snmr_tail_diag.py mt0_deck1832.txt 1832 0.70
```

`.mt0`처럼 헤더가 있는 CSV/표 형식이면, 스크립트 상단의
`COLUMN = None` 을 SNMR 측정 이름으로 바꾼다 (예: `COLUMN = "snmr"`).
숫자로 파싱되지 않는 줄은 자동으로 건너뛰므로 헤더/주석은 신경 쓰지 않아도 된다.

의존성은 **numpy뿐**이다. matplotlib이 있으면 그림도 저장되고, 없으면
그림만 건너뛰고 숫자는 정상 출력된다. 단위는 V/mV 자동 판별한다.

## 5. 무엇을 회신하는가

각 조건마다 아래 형식의 **블록 한 개**가 출력된다. **이 블록만** 전달하면
된다 (원시 데이터는 사내에 남는다). 9개 조건이면 블록 9개.

```
=== TAILDIAG v1 | deck 1832 | Vop 0.70 | n=100000 ===
unit=mV  mean=82.1234  std=13.9876  z_naive=5.8712
skew=-0.1502(ref-0.1395)  exkurt=+0.0891
qz_emp : p50=+0.024  p15.9=-0.991  p2.28=-2.080  p0.135=-3.282  p0.02=-3.893
qz_gaus: p50=+0.000  p15.9=-1.000  p2.28=-1.999  p0.135=-3.000  p0.02=-3.540
qz_se  : p50=0.004  p15.9=0.005  p2.28=0.009  p0.135=0.026  p0.02=0.059
obs_min=-4.388
chi2   : MIN2(rho=+0.00)=14.7  MIN2(rho=-0.25)=43.3  ...   dof=5
best=MIN2(rho=+0.00)
z_true@6.5=5.822  zbias=+0.678  -> NON-GAUSSIAN -> Vmin optimistic; correction +0.68 sigma
=== END TAILDIAG ===
```

같은 내용이 `taildiag_<deck>_<vop>.txt`로도 저장되고, 그림은
`taildiag_<deck>_<vop>.png`(히스토그램 + 왼쪽 꼬리 Q-Q)로 저장된다.
그림은 보내지 않아도 되지만, 보내주면 판정 교차 확인에 쓸 수 있다.

### 결과를 읽는 법 (담당자용)

- `best=GAUSS` + `zbias=+0.000` → **꼬리가 정규분포와 일치. 보정 불필요.**
- `best=MIN2(rho=...)` + `zbias=+0.xx` → **꼬리가 두꺼움. 그만큼 Vmin이 낙관적.**
  `zbias` × (1/13.2 V) ≈ Vmin 오차. 예: zbias +0.68 → 약 52 mV.
- `chi2` 줄에서 `GAUSS` 값이 `dof`(=5)의 3배 미만이면 가우시안으로 설명
  가능한 범위 → 스크립트가 자동으로 GAUSSIAN-CONSISTENT로 판정한다.

## 6. 검증 상태

스크립트는 정답을 아는 합성 데이터 3종으로 검증 완료:

| 합성 입력 | 판정 결과 | zbias | 기대값 |
|---|---|---|---|
| 진짜 가우시안 | GAUSS (chi2 3.7 vs dof 5) | +0.000 | ✅ 보정 불필요 |
| min of 2 독립 lobe | MIN2(ρ=0.00) | +0.678 | ✅ 이론 +0.70 |
| min of 2, ρ=−0.5 | MIN2(ρ=−0.50) | +1.233 | ✅ 더 큰 편향 |

즉 편향이 없으면 없다고, 있으면 크기까지 맞게 답한다.

## 7. 우선순위 (전체를 못 돌릴 경우)

리소스가 빠듯하면 아래 순서로 줄인다. **3개만 돌려도 판정은 가능하다.**

1. **981** (Vmin ≈ T0 spec 0.625V — 판정이 가장 직접적으로 걸리는 조건)
2. **435** (FSG 최악 읽기 코너 — 가장 보수적으로 봐야 할 조건)
3. **147** (local-σ 최고 — 편향이 가장 클 것으로 예상되는 조건)
4. 1832 (local-σ 최저 — 3번과 대비해 편향의 local-σ 의존성 확인)
5. 나머지

MC 횟수를 줄이는 것보다 **조건 수를 줄이는 편이 낫다.** 50,000회 미만으로
내려가면 꼬리가 보이지 않아 조건을 아무리 많이 돌려도 판정이 안 된다.
