## 1. 서론: 왜 이 연구를 하는가

### 1.1 SRAM과 Vmin의 중요성

SRAM은 현대 SoC(System-on-Chip)에서 가장 큰 면적을 차지한다. 예를 들어
모바일 AP(Application Processor)에서 SRAM은 전체 칩 면적의 30~60%를 차지하며,
CPU 캐시, GPU 레지스터 파일 등 핵심 기능 블록의 대부분이 SRAM으로 구성된다.

SRAM의 **최소 동작 전압(Vmin)**은 셀이 읽기와 쓰기를 안정적으로 수행할 수 있는
최저 전압이다. Vmin이 높으면 칩 전체의 동작 전압이 높아져서 소비 전력이 증가하고,
배터리 수명이 단축된다. 따라서 Vmin을 가능한 낮추는 것이 저전력 칩 설계의
핵심 목표 중 하나이다.

그런데 Vmin은 공정 변동(process variation)에 강하게 의존한다. 반도체 제조 과정에서
트랜지스터의 게이트 길이, 도핑(doping) 농도, 산화막 두께 등이 웨이퍼 내부에서
일정하지 않다. 이러한 변동으로 인해 같은 설계라도 웨이퍼의 위치에 따라
트랜지스터 특성(threshold voltage, 이동도 등)이 달라지고, 이는 곧 Vmin의 변동으로
이어진다.

### 1.2 기존 방식의 한계: 시뮬레이션 리소스 문제

현재 업계에서 Vmin을 추정하는 표준 방식은 **Monte Carlo(MC) 시뮬레이션**이다.
하나의 공정 변동 조건에 대해 수천~수만 개의 랜덤 트랜지스터 특성을 생성하고,
각각에 대해 HSPICE(또는 PrimeSim) 회로 시뮬레이션을 실행하여 SNM(Static Noise
Margin) 분포를 얻는다. 이것이 반복되는 조건의 수는 통상 1,000~2,000개이다.

이 방식의 문제는 **시뮬레이션 리소스가 막대하다는 점**이다:

- 조건당 MC 시뮬레이션: 1,000~5,000회 (SNM 분포 수집)
- 총 시뮬레이션: 1,000 조건 × 3,000 MC × 5 전압 = **1,500만 회**
- HSPICE 1회 시뮬레이션 소요: 수분~수십분 (모델 복잡도에 따라)
- 총 소요 시간: **수주~수개월** (병렬화해도 상당한 리소스)

여기에 리소스 문제는 단순히 시간만의 문제가 아니다. **PDK(Process Design Kit)와
관련된 라이선스, 라이선스당 시뮬레이션 동시 실행 수 제한, 서버 비용** 등이 모두
추가 비용으로 발생한다. 특히 첨단 노드(FinFET, GAA 등)로 갈수록 PDK 모델이
복잡해지고 시뮬레이션 1회당 소요 시간이 길어지며, 이 문제는 더욱 악화된다.

### 1.3 리소스 절감의 현실적 가치

우리가 제안하는 방법은 **단 한 번의 시뮬레이션 예산으로 순방향과 역방향 질의를
모두 처리**한다. 기존 방식에서는:

- **순방향**: "이 조건에서 Vmin은 얼마인가?" → MC 시뮬레이션 필요
- **역방향**: "Vmin = 0.6V 이하인 조건의 경계는?" → 격자 탐색으로 수백~수천 회 추가 MC

반면, 우리 방법은:

- **순방향**: GP 대리모델 학습 후 즉시 예측 (시뮬레이션 불필요)
- **역방향**: 미분 가능 파이프라인의 gradient로 경계를 직접 탐색 (추가 시뮬레이션 불필요)

이를 통해 **동일한 시뮬레이션 예산으로 기존 대비 10~100배 많은 조건을 분석**할 수 있으며,
특히 리소스가 제한된 사내 팹 환경에서 실질적인 가치를 제공한다.

이 주장의 실제 메커니즘 — 조건당 MC 샘플이 실제로 얼마나 적어도 되는지(§4.5),
그리고 개선이 둔화되기 전까지 실제로 몇 개의 조건을 시뮬레이션할 가치가
있는지(§5.5) — 를 밝혀야 "예산을 더 많은 조건에 쓰라"는 말이 구호가 아니라
숫자로 뒷받침되는 결정이 된다.

## 2. 문제 설정

### 2.1 6T SRAM 셀과 읽기 안정성

`[Fig: 6T SRAM 셀 구조도]`

6T SRAM 셀은 여섯 개의 트랜지스터로 구성된다:

- **PU (Pull-Up)**: 2개의 PMOS 트랜지스터. 데이터를 '1'로 유지한다.
- **PD (Pull-Down)**: 2개의 NMOS 트랜지스터. 데이터를 '0'으로 유지한다.
- **PG (Pass-Gate)**: 2개의 NMOS 트랜지스터. 워드 라인(WL) 신호로 셀에 접근한다.

읽기 동작에서 셀의 안정성은 **버터플라이 곡선**으로 평가된다. 왼쪽/오른쪽
반전기(Inverter)의 전압 전이 특성(VTC)을 겹쳐 그린 곡선에서, 두 개의 'lobe'
(공기구 모양 영역)의 최소 크기가 SNM(Static Noise Margin)이다. SNM이 작을수록
읽기 동작 시 데이터가 뒤집힐 위험이 크다.

직관적으로 말하면, 각 lobe는 셀의 절반이 비트가 뒤집히기 전까지 견딜 수
있는 전기적 "떠밀림"의 크기를 나타낸다. 읽기가 실패하려면 두 절반 중
어느 한쪽만 무너져도 충분하므로, 실제로 의미 있는 값은 현재 더 약한 쪽
lobe — 즉 최소값이다.

`[Fig: 버터플라이 곡선과 SNM]`

### 2.2 읽기 SNM의 lobe 통계

MC 시뮬레이션에서는 수천 개의 랜덤 샘플에서 SNM 분포를 얻는다. 관례적으로
수집하는 것은 min의 통계량 (μ_SNMR, σ_SNMR)이다. 그러나 여기서 중요한 문제가
있다.

SNM은 두 lobe의 최소값이다. **최소값 분포의 좌측 꼬리는 모멘트를 맞춘
가우시안보다 무거워서**, 단순히 z = μ/σ를 적용하면 실패 확률을 체계적으로
과소평가한다. 예를 들어 Z ≈ 6 수준에서 이 편향은 +0.7σ(독립 lobe)에서
+1.9σ(역상관 lobe)까지 도달한다. 이는 256 Mb 어레이의 6σ 수준 수율 추정에
치명적인 오차를 일으킨다.

왜 최솟값을 취하면 꼬리가 더 두꺼워질까? 같은 어려운 시험을 보는 두 학생을
떠올려보자. 각자 개별적으로는 낙제할 확률이 낮더라도, "둘 중 적어도 한
명이 낙제할 확률"은 각자의 확률보다 항상 크다. 그리고 두 학생의 컨디션이
함께 오르내린다면(같은 이유로 컨디션이 나쁜 날 등), 그 결합 확률은 더욱
커진다. 읽기 실패도 마찬가지다 — 두 lobe 모두가 아니라 어느 한쪽만
무너져도 실패이므로, 실제 실패율은 관측된 최솟값에 가우시안을 그대로
맞췄을 때 나오는 값보다 항상 같거나 크며, 흔히 눈에 띄게 크다. 바로 이
간극을 메우기 위해 아래의 lobe 분해 z-score를 사용한다.

### 2.3 Lobe 분해 유효 z-score

우리는 두 lobe의 개별 통계 (μ_L, σ_L, μ_R, σ_R, ρ_LR)에서 정확한 실패 확률을
계산한다:

```
p_fail = P(L < 0) + P(R < 0) − P(L < 0, R < 0)
Z_eff = Φ⁻¹(1 − p_fail)
```

여기서 결합항은 **이변량 정규 CDF(Owen's T 함수)**로 폐형식 계산이 가능하며,
모든 입력에 대해 매끄럽다(미분 가능). 이를 통해 min-통계의 편향을 제거하면서도
GP 대리모델의 gradient 흐름을 방해하지 않는다.

### 2.4 Vmin 정의와 수율 목표

어떤 조건 x에서, 전압 격자 Vop ∈ {0.4, 0.5, 0.6, 0.7, 0.8} V에 대해
z(Vop) = μ/σ가 목표 z-score Z_t와 교차하는 전압을 **선형 보간**한 것이 Vmin(x)이다.

Z_t는 어레이 수율 모델에서 유도한다. 256 Mb 어레이에서 Poisson 수율 99%를
보장하려면:

```
p_fail = −ln(0.99) / (256 × 10⁶) ≈ 3.9 × 10⁻¹⁰
Z_t = Φ⁻¹(1 − p_fail) ≈ 6.50
```

z(0.4 V) > Z_t인 조건은 Vmin이 표본 전압 범위 아래에 있으므로 **좌측 censoring**으로
표시하고 연속 오차 지표에서 제외한다.

### 2.5 역문제: 왜 순방향만으로는 부족한가

목표 전압 V*에 대해, {x : Vmin(x) = V*}는 9차원 변동 공간의 **초곡면(hypersurface)**,
즉 등고선이다. 설계자가 실제로 묻는 것은:

> "어떤 변동 조합이 목표 Vmin을 위반하는가?"
> "위반하는 조건을 만족시키기 위해 필요한 최소 어시스트(wordline underdrive 등)는?"

이것은 **역문제**이다. 기존 방식에서는 이 등고선을 찾으려면 격자 탐색(grid search)으로
아주 많은 점에서 MC를 실행해야 한다. 예를 들어 (cn, pu) 2차원에서도 50×50 = 2,500회,
9차원이면 탐색 공간이 기하급수적으로 증가한다.

우리 방법은 미분 가능한 Vmin(x)에 대한 **gradient 하강**으로 이 문제를 푼다.
목표 등고선 위의 점을 gradient로 직접 찾아가므로, 격자 탐색 대비 100배 이상
효율적이다.

## 3. 데이터 설계

### 3.1 입력 공간: 9차원 변동 매개변수

셀 트랜지스터의 변동은 9개 차원으로 기술한다. PG와 PD는 동일한 NMOS 플레이버이므로,
공통 변동(common)과 PG-PD 간 skew로 분해한다.

| 변수 | 의미 | 범위 | 단위 |
|---|---|---|---|
| cn | NMOS 공통 Vth 시프트 (PG=PD 기저) | ±60 | mV |
| sk | PG−PD Vth skew | ±20 | mV |
| pu | PMOS Vth 시프트 | ±60 | mV |
| lpu | PU local-σ 배율 | [0.7, 1.3] | 비율 |
| l_com | NMOS local-σ 공통 | [0.7, 1.3] | 비율 |
| l_sk | NMOS local-σ PG-PD skew | ±0.075 | 비율 |
| mpu | PU 이동도 배율 | [0.7, 1.3] | 비율 |
| m_com | NMOS 이동도 공통 | [0.7, 1.3] | 비율 |
| m_sk | NMOS 이동도 PG-PD skew | ±0.075 | 비율 |

**deck 파라미터 파생 규칙**:
- Vth: PG = cn + sk, PD = cn − sk
- Local-σ: PG = l_com + l_sk, PD = l_com − l_sk
- 이동도: PG = m_com + m_sk, PD = m_com − m_sk

### 3.2 공통+skew 파라미터화의 근거

PG와 PD는 같은 NMOS 플레이버이므로, 지배적 변동 원인(게이트 스택, 채널 도핑,
애닐, 리소그래피 CD 등)을 **공유**한다. W/L, 레이아웃 환언, 플레이버 차이로
불완전한 추적(imperfect tracking)이 발생한다.

장치별 독립 샘플링은 같은 플레이버가 mismatch 수준에서 ±30%씩 반대로
갈라지는, **실공정에 존재하지 않는 상태**에 설계점을 낭비한다. 공통+skew 분해가
만드는 암묵적 상관:

```
corr(l_PG, l_PD) ≈ 0.88
```

이는 동일 플레이버 추적 상관의 통상 범위(0.85~0.95)에 있으며, Vth의 cn/sk 구조
(ρ ≈ 0.80)와 일관된다. 공통과 skew는 **독립으로 샘플링**하며, 이 성질은
§5.6의 분산 기반 민감도 분석(Sobol 지수)이 요구한다.

`[Fig: (cn, pu) 평면 사분면 가중 + (l_com, l_sk) 박스 → (l_PG, l_PD) 대각 띠]`

### 3.3 실험계획: 리소스 절감을 위한 전략

읽기(SNMR)와 쓰기(Vtrip)는 서로 다른 최악 사분면에서 열화한다:

- **SNMR**: FSG (cn < 0, pu > 0)에서 최악 — NMOS가 빠르고 PMOS가 느려 읽기 불안정
- **Vtrip**: SFG (cn > 0, pu < 0)에서 최악 — NMOS가 느리고 PMOS가 빨라 쓰기 실패

따라서 metric별로 별도 deck 세트를 구성하고, (cn, pu) 사분면 가중을 달리한다:

| metric | FSG 가중 | FN 가중 | SN 가중 | SFG 가중 |
|---|---|---|---|---|
| SNMR | 45% | 20% | 15% | 20% |
| Vtrip | 10% | 15% | 30% | 45% |

이렇게 하면 **같은 2,000 조건으로도 최악 조건 영역의 해상도가 2~4배 향상**된다.
조건은 quadrant별 독립 스트림의 결정적 난수(PCG64)로 생성한다.

각 deck 세트: 2,000 조건 × 5 Vop = **10,000 시뮬레이션** (metric당).
총 2 metric = 20,000 시뮬레이션. 기존 격자 탐색 대비 약 100배 절감.

### 3.4 설계 함정: mirror-twin 누수

초기 파일럿 설계에서 발견한 중요한 문제를 공유한다. 하나의 QMC 스트림을 네
사분면에 재사용하고 cn, pu의 부호만 반전시킨 설계에서:

- 조건의 **75%**가 나머지 7개 좌표를 공유하는 mirror-twin을 가짐
- 무작위 hold-out에서 test 조건의 **약 74%**가 train에 쌍둥이를 둠
- 정확도 지표가 **낙관적으로 오염**됨

우리는 이를 전사된 조건과 생성기의 포렌식 대조로 발견하였고, 본 배치에서
**(i) 사분면별 독립 스트림으로 원인 제거**, **(ii) mirror-group 단위 분할 강제**로
해결하였다. 대리모델 검증에서 유사한 설계 유래 누수는 지표를 조용히 부풀리므로,
**실험 설계의 재현 코드와 분할 규칙을 함께 보고**하는 것을 권고한다.

## 4. 방법

### 4.1 GP 대리모델: ML 개념 설명

**Gaussian Process(GP)**는 "유한한 데이터 포인트에서 함수의 분포를 추정하는
비모수적 Bayesian 방법"이다. 우리 문제에서는:

- **입력**: 9차원 변동 매개변수 + 전압 (x = [cn, sk, pu, lpu, l_com, l_sk, mpu, m_com, m_sk, Vop])
- **출력**: SNM의 통계량 (μ_SNMR, σ_SNMR)
- **GP가 학습하는 것**: 입력에서 (μ, σ)로 가는 **함수의 분포**

GP의 장점:
1. **불확실성 정량**: 예측과 함께 분산(uncertainty)을 제공한다.
2. **적은 데이터로도 동작**: 2,000 조건으로도 9차원 공간을 학습할 수 있다.
3. **미분 가능**: gradient 기반 최적화(역추정)에 직접 사용할 수 있다.

**μ GP**: Matern 5/2 커널 + ARD(Auto-Relevance Determination). 각 입력 차원에
대한 lengthscale을 자동으로 학습하여, 어떤 차원이 출력에 더 중요한지 판별한다.

직관적으로 lengthscale은 다음 질문에 답한다: "이 입력을 조금 움직였을 때,
GP의 예측이 눈에 띄게 바뀌기까지 얼마나 멀리 가야 하는가?" lengthscale이
짧으면 그 축에서 출력이 민감하고 변화가 심하다는 뜻이고(작은 움직임도
중요), lengthscale이 길면 넓은 범위를 보간해도 예측이 크게 변하지 않는다는
뜻이다. ARD는 9개 입력 차원 각각에 이 질문의 답을 미리 가정하지 않고
데이터로부터 따로 학습하게 하는 것이며, 그래서 학습된 lengthscale이
(거칠지만) 자연스러운 중요도 순위가 된다 — 이는 §5.6에서 정량적으로 다시
다룬다.

**σ GP**: 가산 커널(additive kernel). 동작 전압 그룹(Vop)과 장치 변동 그룹으로
커널을 분리하여 구조적 정보를 반영한다.

### 4.2 입력 표준화: 숨겨진 핵심

mV, V, 비율 등 **다양한 단위의 입력이 혼재**할 때, 입력 표준화가 없으면
lengthscale 초기화가 감당하지 못하는 **조용한 미수렴**이 발생한다. 우리 초기
실험에서 물리 제약의 효과로 오인됐던 개선의 대부분은 실은 **표준화의 효과**였다
(§5.5). 따라서 모든 입력은 학습 통계로 표준화한다.

### 4.3 미분 가능 물리 계층

GP의 출력 (μ, σ)을 Vmin으로 변환하는 계층은 학습된 근사가 아니라 **해석적
제약(analytic constraint)**으로 작동한다:

```
1. 각 조건에 대해 5개 전압의 (μ, σ) 예측
2. z(Vop) = μ(Vop) / σ(Vop) 계산
3. z(Vop)가 Z_t = 6.50을 교차하는 전압을 선형 보간
4. → Vmin(x)
```

교차 구간 선택은 이산이지만, 구간 내부에서 1차 미분이 잘 정의된다. censored
조건은 플래그로 분리된다. 이 계층은 **학습 파라미터가 없으며**,
GP의 사후 평균과 분산에만 의존한다.

### 4.4 물리 제약

GP에 물리적 지식을 주입하는 세 가지 제약:

1. **Corner Anchoring**: 4개 글로벌 코너(cn±60, pu±60) × 5 Vop의 가상
   관측을 학습 데이터에 증강한다. Exact GP에서 이는 하드 제약으로 작동한다.
   쉽게 말해, "이 네 개의 극단적이고 물리적으로 잘 이해된 코너에서는 이미
   답을 알고 있으니, 다른 영역의 fitting 때문에 여기서 멀어지지 말라"고
   GP에 알려주는 것이다. 지도 제작자가 정밀 측량된 몇 개의 랜드마크에 손으로
   그린 지도를 고정시키는 것과 같은 원리다.

2. **단조 패널티(Monotonicity Penalty)**: 전압이 올라가면 z-score는 일반적으로
   증가한다. ReLU(−∂μ/∂Vop)² 형태의 패널티를 probe 점에서 사후 미분으로 평가한다.
   실무적으로 이는 "공급 전압을 올렸는데 평균적으로 셀 안정성이 오히려
   나빠진다"는, 실제 SRAM 셀에서는 거의 나타나지 않는 패턴을 모델이 예측하지
   않도록 막아준다. 데이터로 다시 학습시키는 대신, 이미 알려진 사실을 미리
   알려주는 셈이다.

3. **Pelgrom 선형 경향**: σ(Vop)의 선형 증가 경향을 약한 정규화로 건다.
   Pelgrom의 법칙에 따라 전압이 높아지면 변동의 절대 영향이 커진다. 이는
   수십 년간 축적된 트랜지스터 mismatch 측정 데이터와 일치하는 경향이다.
   GP를 이 잘 알려진 형태 쪽으로 살짝 유도하는 것은, 2,000개 조건만으로 이
   사실을 처음부터 다시 발견하도록 요구하는 대신 기존 실리콘 지식을
   활용하는 것이다.

### 4.5 Noise-aware GP

조건별 부트스트랩 표준오차(sem_μ, sem_σ)가 **FixedNoise 우도**로 들어간다.
이를 통해:

- **저예산 조건**은 자동으로 하향 가중된다.
- **혼합 예산**이 한 모델에 공존한다: 저 fidelity가 같은 시뮬레이터의 적은
  표본일 뿐이라면, heteroscedastic 단일 GP가 옳은 모델이다.
- Kennedy–O'Hagan 구조의 편향항은 불필요하다.

직관적으로 비유하면, 크기가 다른 여론조사 결과를 하나로 합치는 상황과
같다 — 1만 명을 대상으로 한 조사는 50명을 대상으로 한 조사보다 훨씬 더
신뢰할 만하며, 두 조사의 평균 응답이 같더라도 마찬가지다. Noise-aware
GP는 이 논리를 시뮬레이션 조건에 그대로 적용한다: 많은 MC 샘플로 뒷받침된
조건은 자동으로 더 신뢰할 만한 값으로, 적은 샘플로 뒷받침된 조건은
자동으로 덜 신뢰할 만한 값으로 취급되며, 저예산 조건을 위한 별도의
보정항이 필요 없다.

이는 총 시뮬레이션 예산을 실제로 어떻게 써야 하는가에 직접적인 이득을
준다. GP는 9차원 변동 공간에서 서로 가까운 조건들끼리 통계적 힘을 빌려
쓴다 — 매끄러운 추세선이 표본이 적은 한 점에 대해서도 자신 있게 말할 수
있게 해주는 것과 같은 원리다. 그래서 개별 조건 하나하나가 그 자체로
신뢰할 만한 값을 내려고 비싼 고-N_MC 배치를 따로 확보할 필요가 없다.
조건당 적당한 MC 예산만으로 충분한 이유는, 주변 설계 공간 전체가 사실상
그 점의 값을 보증해주기 때문이다. 바로 이 점이, 정해진 총 시뮬레이션
예산을 소수의 조건에 과도하게 투입하는 대신 9차원 공간의 더 많은 서로
다른 조건을 커버하는 데 쓸 수 있게 해주는 근거다 — 이것이 바로 이
방법론이 애초에 존재하는 이유인 폭(coverage) 대 깊이(조건당 샘플 수)의
자원 배분 결정이며(§1.2–1.3), §5.5의 예산-정확도 곡선에서 구체적인
숫자로 확인된다.

### 4.6 Gradient 역추정

역문제 해결을 위한 최적화 과정이다. 개념적으로 이는 안개 낀 언덕에서
목표 고도까지 감각만으로 내려가는 것과 같다. 매 걸음마다 gradient가
어느 방향이 가장 가파른 내리막인지 알려주고, Adam은 그 기울기 정보를
안정적인 걸음 크기와 방향으로 바꿔주는 잘 검증된 규칙이며, sigmoid
재매개화는 각 걸음이 물리적으로 타당한 소자 변동 범위 안에 머물도록 하는
보이지 않는 울타리 역할을 한다.

1. 입력 x를 **leaf 텐서**로 설정 (sigmoid 박스 재매개화로 경계 유지)
2. **(Vmin(x) − V\*)²**을 Adam 최적화로 최소화
3. 다중 시작점에서 수렴 확인
4. 각 수렴점을 해당 슬라이스의 **1차원 bisection**과 대조하여 검증

이 과정은 격자 탐색 없이 등고선 위의 점을 직접 찾으므로, 고차원에서도 효율적이다.

**핵심 발견**: 물리 제약의 효과를 정확히 평가하려면 **입력 표준화를 통제**해야 한다.
표준화 없이 물리 제약만 추가하면, 대부분의 개선은 표준화에서 비롯된다.

**총 시뮬레이션 예산을 어떻게 정할 것인가.** MC 캠페인을 계획하는 사람이라면
누구나 마주치는 매우 실용적인 질문이 있다: 도대체 몇 개의 조건이면 충분한가?
너무 적게 돌리면 드문 실패 영역을 놓칠 위험이 있고, 필요 이상으로 많이
돌리면 다음 설계나 공정 split에 쓸 수 있었던 시뮬레이터 시간을 낭비하는
것이다. 우리는 학습 세트를 여러 크기 N으로 서브샘플링하여 각 크기에서
대리모델을 다시 fitting함으로써 이 질문에 실증적으로 답하고, 예산-정확도
곡선을 얻는다.

점점 줄어든다. 실무적으로, 이 지점이 바로 "MC 배치를 몇 번 돌려야 하는가"를
감이 아니라 근거 있는 결정으로 바꿔주는 숫자다: 무릎을 지난 뒤에는 추가
조건에 HSPICE 시간을 더 쓰는 것보다, 실패 경계 근처 조건들의 MC 샘플
수를 늘려 깊이를 더하거나(§4.5의 noise-aware GP가 이를 자동으로 흡수한다)
아예 다른 설계 코너를 조사하는 데 쓰는 편이 낫다 — 이미 대리모델이
안정적으로 외삽할 수 있는 영역을 더 넓히는 데 쓰는 것보다 낫다는 뜻이다.
이는 §1.2–1.3과 §4.5에서 소개한 폭 대 깊이의 트레이드오프를 이제 수치로
확인한 것이다. 실 9차원 배치에서의 대응 곡선은 `[TBD]`이다.

### 5.6 민감도 분석

**이 분석이 답하는 질문.** 이 논문을 읽는 공정·소자 엔지니어가 궁극적으로
알고 싶은 것은 이것이다: *우리가 추적하는 9개 변동 요인 중, 실제로 Vmin을
움직이는 것은 무엇이고, 더 느슨하게 관리해도 안전한 것은 무엇인가?* 이
질문에는 비용이 크게 다른 두 가지 도구로 답할 수 있으며, 본 연구는 둘 다
보고한다.

**ARD lengthscale (사실상 공짜).** §4.1에서 설명했듯, GP는 학습 데이터에
fitting하는 과정에서 이미 차원별 lengthscale을 학습하므로, 이를 읽어내는
데 추가 계산이 필요 없다. 다만 한계가 있다 — 이것은 *데이터 자체*에 대한
직접적인 진술이 아니라 *fitting된 모델*의 속성이다. 두 입력이 상관되어
있으면 왜곡될 수 있고(그래서 §3.2에서 l_com과 l_sk를 의도적으로 독립
샘플링한다), "이 입력이 단독으로 중요한지"와 "다른 입력과의 상호작용으로만
중요한지"를 깔끔하게 구분하지 못한다.

**Sobol 지수 (엄밀하지만 원칙적으로는 비싼 대안).** 분산 기반(Sobol)
민감도 분석은 입력-출력 관계에 더 직접적인 질문을 던진다: *다른 모든
입력을 고정하고 이 입력 하나만 자유롭게 둔다면, Vmin 전체 변동폭 중
얼마가 사라지는가?* 이를 정확히 계산하려면 개별 효과와 상호작용 효과를
통계적으로 분리할 수 있을 만큼 많은 수(통상 수만 개)의 입력 조합에서
함수값을 평가해야 한다. 이를 실제 HSPICE Monte Carlo에 직접 적용한다면,
이 프로젝트의 조건당 2,000개 배치로는 어림도 없는 시뮬레이션 예산이
필요하다 — 바로 이 때문에 회로 수준 수율 연구에서 Sobol 분석이 실무적으로
거의 쓰이지 못하는 것이다. 그런데 여기서는 사정이 다르다: GP 대리모델을
한 번 학습시키고 나면, 그것을 평가하는 데는 회로 시뮬레이션의 수 분이
아니라 수 밀리초가 걸릴 뿐이므로, Sobol 추정에 필요한 수만 번의 대리모델
질의는 대리모델을 학습시킨 *원래의* 시뮬레이션 예산 위에 사실상 추가 비용
없이 얹힌다. 다시 말해, 순방향·역방향 파이프라인을 학습시키는 데 이미
지불한 동일한 MC 예산이, 추가 회로 시뮬레이션 없이 엄밀한 민감도 분석
전체를 "덤으로" 사준다.

ARD와 Sobol을 나란히 보고하는 이유(그림 7)는, 공짜이면서 모델-내부적인
신호와 (일반적으로는 비싸지만 여기서는 그렇지 않은) 모델-외부적인 신호가
서로 일치하는지 자체가 정보이기 때문이다 — 둘이 일치하는 곳은 두 개의
독립적인 관점에서 모두 신뢰할 수 있는 순위이고, 불일치하는 곳은
상관관계나 상호작용 효과를 더 들여다봐야 할 입력 쌍을 알려주는 신호다.
이 설계에서의 핵심 질문:

1. **ℓ_cn < ℓ_pu** (PG 지배 계층)가 성립하며, Sobol 순위도 이에
   동의하는가?
2. **l_sk/m_sk**가 단독 효과가 아니라 다른 입력과의 상호작용을 통해서만
   작동하는 2차 효과인가 — 그렇다면 이는 작은 1차 Sobol 지수와 상대적으로
   큰 total-order 지수로 나타나야 한다.

## 6. 한계와 위협

1. **z = μ/σ의 가우시안 외삽**: 절대 실패율 예측기가 아니라 업계 표준 마진 지표.
2. **단일 노드·단일 셀 토폴로지**: 결과의 일반화 범위.
3. **배율 스필 구간** [0.625, 0.7) ∪ (1.3, 1.375]: compact model 보정 범위 가장자리.
4. **PDK 비공개**: 절대값 재현 불가 → 해석적 testbed 코드와 정규화 축 결과 공개.

## 7. 관련 연구

- MFNN+IS (Guo et al., ISEDA'24): 순방향 수율 추정
- Bayesian active learning (Yin et al., DAC'22, ASPDAC'23): 순방향 수율 추정
- Tail-accurate IS (Liu et al., DAC'23, OPTIMIS): 꼬리 정밀 IS — 상보적
- 해석적 Vmin 모델 (Gupta & Calhoun, TCAS-I'21): 해석적 접근 — GP는 유연성
- QMC 수율 해석 (Singhee & Rutenbar, TCAD'10): 설계 기반

## 8. 결론

GP 대리모델과 미분 가능 물리 계층으로 SRAM Vmin의 순방향·역방향 질의를
**단일 시뮬레이션 예산**에서 처리하는 파이프라인을 제안하고, 첨단 노드 데이터에서
검증했다.

핵심 기여:
1. **리소스 절감**: 동일 예산으로 기존 대비 10~100배 많은 조건 분석
2. **미분 가능 역추정**: gradient로 Vmin 등고선을 직접 탐색
3. **Lobe 분해 z-score**: min-통계 편향을 폐형식으로 제거
4. **Noise-aware GP**: 이질적 MC 예산을 단일 모델에 통합

## 부록 C. 평이한 용어 해설

| 용어 | 쉬운 설명 |
|---|---|
| SNM (Static Noise Margin) | 읽기 동작 중 SRAM 셀이 저장된 비트가 뒤집히지 않고 견딜 수 있는 최대 방해(disturbance)의 크기. |
| Vmin | 어레이의 모든 셀이 올바르게 읽고 쓸 수 있다고 기대되는 가장 낮은 공급 전압. |
| 공정 변동(process variation) | 반도체 제조 과정에서 불가피하게 발생하는, 칩 간·셀 간 트랜지스터 특성 차이. |
| 버터플라이 곡선 | SRAM 셀의 두 cross-coupled 인버터의 전압 전이 곡선을 겹쳐 그린 것으로, 겹치는 "lobe"가 읽기 안정성을 시각화한다. |
| z-score (본문 맥락) | 정규화된 "실패까지의 거리" 지표 — 평균 조건과 실패 지점 사이에 표준편차 몇 개만큼의 여유가 있는지를 나타낸다. |
| Gaussian Process (GP) | 곡선/곡면을 fitting하면서, 각 예측과 함께 그 예측에 대한 신뢰도(불확실성)까지 함께 알려주는 방법. |
| 커널 / lengthscale | "두 입력이 얼마나 떨어져 있어야 그 출력이 서로 무관해 보이는가"에 대한 GP 내장 기준. |
| ARD (Automatic Relevance Determination) | GP가 입력 차원마다 별도의 lengthscale을 학습하게 하여, 어떤 입력이 더 중요한지 판별하게 하는 방법. |
| Heteroscedastic / noise-aware 우도 | 모든 데이터를 동일하게 신뢰하는 대신, 각 데이터 포인트가 얼마나 신뢰할 만한지를 모델에 알려주는 방식. |
| Owen's T 함수 | 상관된 두 가우시안 확률변수가 동시에 어떤 임계값 아래에 있을 확률을 폐형식으로 계산하는 함수. |
| Corner anchoring | 이미 답을 아는, 물리적으로 의미 있는 몇 개의 기준점을 학습 데이터에 추가하여 모델이 그로부터 벗어나지 못하게 하는 기법. |
| Pelgrom의 법칙 | mismatch 모델링 문헌의 경험 법칙으로, 트랜지스터 mismatch로 인한 변동성이 소자 크기와 바이어스에 따라 예측 가능하게 커진다는 것. |
| Gradient 역추정 | 시행착오로 탐색하는 대신, 미분 가능한 모델의 기울기를 이용해 목표 출력 쪽으로 곧장 걸어가는 방법. |
| Hausdorff 거리 | 두 곡선(등고선) 사이의 평균 차이가 아니라, 최악의 경우 벌어지는 간극을 측정하는 방법. |
| Sobol 지수 | 출력의 전체 변동성 중 각 입력(및 입력들의 조합)이 차지하는 비율을 나타내는 통계량. |
| 좌측 censoring (본문 맥락) | 실제 Vmin이 시뮬레이션한 최저 전압보다 낮아서 정확한 값은 모르고 "X 이하"라는 것만 아는 조건. |
